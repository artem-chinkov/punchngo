# PUNCH 'N' GO — Combat Sandbox v0.1

Одна тестовая схватка на парковой аллее. Герой идёт вперёд сам, останавливается перед группой из трёх врагов и продолжает путь после победы. Правила боя взяты из [GAME_DESIGN.md](GAME_DESIGN.md) и [TECH_SPEC.md](TECH_SPEC.md), v1.0.

## Запуск

[Играть на GitHub Pages](https://artem-chinkov.github.io/punchngo/). Изменения в `main` проходят тесты и публикуются через GitHub Actions.

На Mac нужен Node.js 22.12 или новее с npm. В Терминале:

```sh
cd punchngo
npm ci
npm run dev
```

Открой в Safari или другом браузере http://localhost:5173/. Нажми «Начать». Короткое нажатие в игровой области бьёт, удержание поднимает блок. Красный знак предупреждает об атаке, жёлтый открывает окно контратаки. Третий удар короткой серии — хук, который может задеть соседей. После попадания хуком следующая атака доступна через 0,5 с, а блок можно поднять сразу. После победы или поражения доступен повтор.

На iPhone открой Safari в вертикальной ориентации. Подключи Mac и iPhone к одной Wi‑Fi сети и запусти на Mac:

```sh
npm run dev -- --host 0.0.0.0
```

На iPhone открой адрес из строки `Network` в выводе Vite, например `http://192.168.1.25:5173/`. Терминал на Mac должен оставаться открытым. В горизонтальной ориентации на сенсорном устройстве игра показывает подсказку о повороте.

Для панели балансировки добавь `?debug=1` к адресу сервера разработки и нажми **DEV**. Меню приостанавливает бой. «Применить и начать заново» сохраняет числа в этом браузере, «К схватке» пропускает прогулку, «Сбросить» восстанавливает числовые значения по умолчанию. Можно включить неуязвимость и посмотреть FPS, дистанции, состояния AI, текущую цель и сектор удара.

## Модули

- `src/game/SandboxRun.ts` управляет маршрутом и состояниями схватки. `SandboxScene.ts` связывает симуляцию, ввод, HUD и Phaser, обновляя симуляцию фиксированным шагом 1/60 с.
- `src/combat/` содержит урон, выносливость, выбор цели, комбинации, начисление очков и автомат состояний противников с общей очередью атак. Попадания рассчитываются по координатам мира.
- `src/rendering/` проецирует общие координаты дорожки, окружения и противников. Отдельное представление анимирует персонажей, кулаки и эффекты попаданий.
- `src/assets/` содержит реестр, логические размеры, точки опоры и временные текстуры Phaser Graphics. `src/input/`, `src/ui/` и `src/debug/` отвечают за жесты, HUD и балансировку.

## Подключение оригинальной графики

1. Положи PNG или пару PNG + JSON в `public/assets/`.
2. Заполни `src/assets/rasterPack.ts`, используя идентификаторы из `src/assets/ids.ts`. Например:

   ```ts
   export const rasterPack: AssetPack = {
     'park.tree': { png: '/assets/tree.png' },
     thug: {
       png: '/assets/thug.png',
       atlas: '/assets/thug.json',
       poses: {
         idle: ['thug_idle_0', 'thug_idle_1'],
         telegraph: ['thug_windup_0', 'thug_windup_1'],
         attack: ['thug_attack_0', 'thug_attack_1'],
       },
     },
   }
   ```

3. Открой игру с `?assets=raster`. Незаданные изображения используют временные текстуры. У атласа незаданное состояние берёт кадры `idle`, если они есть. Атлас проигрывается с частотой 12 кадров/с.
4. Для врагов держи ступни в одной точке всех кадров, для деревьев и лавочек привязывай основание, для кулаков используй отдельные экранные точки. Размеры и опоры настраиваются в `AssetRegistry.ts`. При подключении графики формулы проекции, AI и зоны боя сохраняются.

`npm test` проверяет бой, проекцию и жесты. `npm run build` проверяет типы и собирает `dist/`. Готовую сборку можно локально открыть через `npm run preview`.
